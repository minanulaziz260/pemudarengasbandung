# PEMUDA RENGASBANDUNG — Official Bio Link & Sawer Admin

Halaman web landing page minimalis untuk tautan bio TikTok **@pemudarengasbandung**, dirancang dengan performa tinggi, responsif untuk perangkat mobile, dan mengadopsi bahasa visual teknikal ala **SanzCloud** (`app.sanzcloud.site`).

---

## Fitur Utama

- **Mode Terang Default (SanzCloud Ice-Blue Theme)**: Tampilan bersih, kontras tinggi, dan nyaman dibaca di bawah sinar matahari.
- **Toggle Mode Gelap / Terang**: Pengunjung dapat beralih ke tema malam (*Deep Navy*) kapan saja dengan tombol di sudut kanan atas.
- **3 Pilihan Metode Sawer Admin**:
  1. **DANA**: Nomor `0831-3693-7804` a.n. M AZIZ (Salin 1-klik & deep link DANA).
  2. **SeaBank**: No. Rekening `9016-6294-1550` a.n. M AZIZ + chip kode bank `535`.
  3. **QRIS All Payment**: Scan QRIS nasional asli untuk semua bank & e-wallet (BCA, Mandiri, BRI, BNI, GoPay, OVO, ShopeePay, DANA) + fitur simpan gambar & modal zoom fullscreen.
- **Efek Audio Taktil Mekanik**: Suara klik mouse haptik pada setiap interaksi tombol dan tab.
- **Lencana Profil Terverifikasi**: Foto profil resmi PR dengan centang biru verified badge.
- **Tautan Cepat**: Menghubungkan langsung ke akun resmi TikTok dan WhatsApp Admin.

## Cara Pasang & Deploy Gratis ke GitHub Pages

1. **Buat Repository Baru di GitHub**:
   - Buka [github.com/new](https://github.com/new).
   - Beri nama repository, misalnya: `pemuda-rengasbandung` atau `link-bio`.
   - Pilih **Public**.

2. **Upload / Push File**:
   - Upload semua file yang ada di dalam berkas ZIP ini ke repository GitHub Anda (pastikan `index.html` berada di root).

3. **Aktifkan GitHub Pages**:
   - Masuk ke tab **Settings** di repository GitHub Anda.
   - Pilih menu **Pages** di bilah sisi kiri.
   - Pada bagian **Build and deployment** > **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
   - Klik **Save**.

4. **Selesai**:
   - Dalam hitungan menit, web Anda akan online secara gratis di:
     `https://<username-kamu>.github.io/<nama-repo>/`
   - Salin link tersebut dan pasang di profil bio TikTok Anda!
